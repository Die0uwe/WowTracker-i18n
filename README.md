# WowTracker-i18n

Localisation files for [WowTracker](https://github.com/Die0uwe/WowTracker) — Slayer Alliance Edition.

## Supported Languages (v3.5.5)

| Code | Language | Status |
|---|---|---|
| nlNL | Nederlands | ✅ Complete (default) |
| enUS | English | ✅ Complete |
| deDE | Deutsch | ✅ Complete |
| frFR | Français | ✅ Complete |
| esES | Español | ✅ Complete |

## Adding a Translation

All strings are defined in `WowTracker/Core/WowTracker.lua` in the `WT_STRINGS` table.

Key categories:
- `GUILD_*` — Guild tab strings
- `QS_*` — Bounty/QuickSet strings  
- `QS_AB_*` — Abundance strings
- `DB_*` — Database strings
- `SYS_*` — System strings
- `PT_*` — Prey Tracker strings
